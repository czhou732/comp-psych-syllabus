# Contributing

This syllabus is a living document. Contributions are welcome.

## How to Suggest Changes

### Adding a Paper
- Open an issue with the title: `[Paper Suggestion] Author (Year) — Title`
- Include: full citation, which module it belongs to, and a 2-3 sentence justification for why it should be included
- If it replaces an existing paper, explain why the replacement is stronger

### Modifying Study Questions
- Open a pull request with your proposed changes
- Study questions should be open-ended, not factual recall
- They should encourage critical thinking about methodology and clinical implications

### Suggesting a New Module
- Open an issue with the title: `[Module Suggestion] — Topic`
- Include: 3-4 candidate papers with citations
- Explain how this module connects to the existing curriculum

## Guidelines
- All suggested papers must be peer-reviewed or published as recognized preprints (bioRxiv, PsyArXiv)
- Prefer foundational/review papers over narrow empirical studies for the core syllabus
- Maintain accessibility for undergraduates — avoid papers that require graduate-level math without providing the necessary background in the syllabus

## Code of Conduct
Be respectful, constructive, and collegial. This is an educational resource built by students for students.
